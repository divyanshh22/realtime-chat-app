About WebChat

WebChat is a real-time messaging application designed to make communication simple and convenient. Open it in your browser, find the person you want to reach, and talk — messages, presence and read receipts arrive instantly, with no refreshes and no clutter.

WHAT IT DOES

What WebChat Offers

Real-time text messaging

Messages are delivered instantly over WebSockets — no refreshing, no waiting for the other person to reload.

User authentication

Secure signup and login with session-based accounts, so only you can access your conversations.

Online / offline presence

See who is online right now and when last-seen people were around, updated live across every page.

Typing indicators

Know when the other person is typing a reply before it even arrives.

Message delivery status

A single tick means sent, a double tick means the message reached the recipient's device.

Read receipts

Delivered ticks turn green the moment your message has actually been read.

User search

Find anyone by username and jump straight into a conversation with them.

UNDER THE HOOD

Technology Behind WebChat

Python Django Django Channels WebSockets Redis PostgreSQL HTML CSS JavaScript Cloudinary Nginx Docker

Django Channels and WebSockets carry the live messages, presence and typing events, with Redis as the channel layer. The interface is plain HTML, CSS and JavaScript — no front-end framework required.
